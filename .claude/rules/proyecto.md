# Reglas generales del proyecto

## Idioma
- El código (variables, funciones, clases, comentarios) se escribe en **español**.
- Excepciones: términos técnicos sin traducción natural (`render`, `fetch`, `state`, `props`, etc.).

## Naming
- Variables y funciones: `camelCase` → `precioTotal`, `añadirAlCarrito`
- Componentes/clases: `PascalCase` → `TarjetaProducto`, `ResumenPedido`
- Archivos: `kebab-case` → `tarjeta-producto.js`, `resumen-pedido.css`
- Constantes globales: `SNAKE_UPPER` → `IVA_GENERAL`, `MONEDA_DEFECTO`

## Estilo de código
- Indentación: 2 espacios.
- Punto y coma al final de cada sentencia.
- Comillas simples para strings, excepto en HTML/templates.

## Git
- Commits en español, imperativos y concisos: `Añade carrito`, `Corrige cálculo de IVA`.
- El `.git` del proyecto está en `/Users/jaime/Desktop/` — no crear uno nuevo dentro de esta carpeta.
